# @kartoffelgames/environment-example-app

An example package that exercises the `page` (dev server) and `build` (bundle + native desktop) commands with a real,
framework-free client page: HTML + CSS + a light interactive TypeScript bundle.

It is not published. It exists so the `page`/`build`/desktop pipeline can be tested end-to-end against actual content.

## Layout

```
page/
  index.html          # loads /index.css and /bundle/app.js
  index.css           # theming via CSS variables + [data-theme]
  source/
    index.ts          # interactive UI (counter, theme toggle, live clock, accent picker, isolation badge)
  bundle/             # GENERATED by the build, app.js (+ .map)
desktop/
  source/
    index.ts          # desktop entry compiled by the desktop build (standalone, does not embed page/)
dist/                 # GENERATED by the desktop build, per-platform app directories (page/ files copied in)
```

The page bundle and the desktop entry are configured in [`deno.json`](./deno.json) as `kg.config.build.files` entries. The desktop entry's `include` copies the built `page/` files into each output directory so the app can serve them.

## Try it

Serve the page with live reload (edit `page/source/index.ts` and save to see it refresh):

```bash
deno task kg page -p=@kartoffelgames/environment-example-app
```

Then open <http://127.0.0.1:8088>.

Produce just the bundles (no desktop compile):

```bash
deno task kg build -p=@kartoffelgames/environment-example-app --types=page,bundle
```

Build the native desktop binary (requires Deno ≥ 2.9 with `deno desktop`). `deno desktop` does not cross-compile, so
this builds only the desktop entry's `output` matching your host OS/arch and skips the others with a message. Build
the remaining platforms on their own OS (e.g. a CI matrix):

```bash
deno task kg build -p=@kartoffelgames/environment-example-app --types=desktop
```

The `crossOriginIsolated` badge on the page turns green when the server sends the COOP/COEP headers. The `page` dev
server emits them, so `SharedArrayBuffer` is available during development.
